## 📊 Analytics

This project uses Vercel Web Analytics to track page views and web vitals. To enable analytics:

1. Deploy the project to Vercel
2. Go to your project settings in the Vercel dashboard
3. Navigate to the Analytics tab
4. Click "Enable Web Analytics"

The analytics script is already integrated in `index.html` and will automatically start tracking once enabled in the dashboard.

## 📦 Deployment

This website can be deployed using Vercel.

1. Install dependencies: `npm install`
2. Import this GitHub repository into Vercel
3. Configure the project settings if necessary
4. Deploy the website
5. Enable Web Analytics in the Vercel dashboard (Analytics tab)
6. Add the live website URL to this README
